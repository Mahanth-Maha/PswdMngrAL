PswdMngrAL

Password Manager Auto Login with Encryption

It's hard to remember different passwords for different sites. Most of us use the same password everywhere, which is vulnerable. PswdMngrAL solves this by securely managing different passwords for you and automating logins with encryption.

This software works best on Windows OS but can run on Mac OS and Linux without the autofill feature. It stores your credentials securely and auto-fills them for you, ensuring convenience and safety.

How to Use

Windows OS

Run the PasswordManager_v1.2_Win64.exe file, create a master password, and you're good to go.

Linux OS

Download PasswordManager_v1_2_deb, give execute permission with: chmod +x ./PasswordManager_v1_2_deb, and then run it: ./PasswordManager_v1.2_deb.

Mac OS

Run the PasswordManager.py script from the PswdMngrWithoutAL directory.

Master Password

Choose a strong master password that includes at least one special character, one number, and one uppercase letter, with a minimum length of 8. For example, use phrases like "ineedgunslotsofguns" or "maybeishouldhavedoneit" for better recall.
